# Anti-Patterns — What Makes HTML Look AI-Generated

## The current clichés (avoid these)

| Anti-pattern | Why it screams AI |
|---|---|
| Warm cream (#F4F1EA) background | Every "editorial" AI artifact uses it |
| One shot of acid-green or vermilion on near-black | The "one pop of color" tic |
| Purple-to-blue gradient hero | Default Vite/Next.js starter energy |
| Inter or Space Grotesk everywhere | Safe choices that signal no choice made |
| Emoji as section markers (🚀 ⚡ 🎯) | Substitutes for actual iconography |
| Universal center alignment | Only honest when the content is a headline |
| Rounded-lg on every card, every button | Sprayed without intent |
| Rounded cards with an accent bar/rail | The "modern dashboard" cliché |
| Hairline broadsheet rules over cramped columns | Mimics editorial without earning it |

## The fix: anchor to subject

Instead of reaching for the safe choice, ask: what does THIS subject's world
look like? A distributed-systems explainer might use terminal greens and
monospace. A career artifact might use warm neutrals and a serif display. The
palette is excavated from the subject, not from the model's defaults.

## When a cliché is what the user wants

If the user explicitly asks for one of these looks, execute it faithfully —
their instructions trump the anti-pattern list. This list protects against
unconscious defaulting, not against deliberate direction.
